# 📚 Collection Manipulator

# 📖 Description

Student Data Organizer is a **Python Command-Line Application** that helps users manage student records efficiently.

This project demonstrates the use of Python collections such as **List, Dictionary, Tuple, and Set** while performing CRUD (Create, Read, Update, Delete) operations.

# ✨ Features

✅ Add Student

✅ Display All Students

✅ Update Student Information

✅ Delete Student

✅ Display Subjects Offered

✅ Exit Program

- 📋 List

- 📅 Tuple
- 🔁 Loops
- 🔀 if-elif-else
- ⌨️ User Input
- 🔍 Searching

- ❌ Deleting Records
