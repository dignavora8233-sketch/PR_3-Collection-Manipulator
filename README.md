# 📚 Collection Manipulator

A simple **Python Command-Line Application** to manage student records using Python Collections. This project demonstrates the practical use of **List, Dictionary, Tuple, and Set** by performing CRUD (Create, Read, Update, Delete) operations.

## 📖 Project Description

The **Student Data Organizer** is a menu-driven Python application that allows users to store and manage student information efficiently. It is designed for beginners to understand how Python collections work together in a real-world application.

Each student record includes:

- 🆔 Student ID
- 👤 Name
- 🎂 Age
- 🏆 Grade
- 📅 Date of Birth (Tuple)
- 📚 Subjects (Set)

The project performs all CRUD operations while demonstrating collection manipulation and user interaction.

## 📂 Data Structure Used

### 📋 List
Stores all student records.

### 📚 Dictionary
Stores information of a single student.

Example:

{
    "ID": "101",
    "Name": "Digna",
    "Age": 17,
    "Grade": "A",
    "DOB": ("03","01","2009"),
    "Subjects": {"DS","DM"}
}

### 📅 Tuple
Stores the student's Date of Birth.
